# UIRef

Your visual memory for building better interfaces.
<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User requested Next.js App Router, TypeScript, Tailwind, customized shadcn primitives, Lucide, MongoDB and Zod. No separate backend or authentication in V1.

## Users

One developer using Codex and Cursor, who recognizes good design but needs help translating reference interfaces into coding constraints.

## Product Purpose

Save screenshots and subjective notes; extract design principles; mix selected aspects into project briefs and implementation prompts; compare implementations.

## Operating Context

Personal local-first development tool, desktop/laptop prioritized with tablet/mobile support. No SaaS, billing, team or enterprise features.

## Current Scope

Foundation and the selected reference Library, now extended with local website capture, uploaded screenshot processing, measured design details, optional OpenAI vision analysis, and reusable single-reference build prompts. The landing page at `/` introduces UIRef; the library lives at `/library`. Vision interpretation requires a server-side provider key; without it, the UI honestly shows measured evidence only. Project mixing and implementation comparison remain future phases.

## Evidence

User's detailed brief and selected second library direction in docs/review/selected-direction.png; approved UIRef landing direction in docs/landing/selected-uiref.png. The landing direction contract is docs/landing/surface.md. Reference screenshots are generated fictional sample content, not real saved websites.

## Accessibility

Keyboard navigation, visible focus, semantic controls, accessible dialogs, reduced motion and readable contrast.
